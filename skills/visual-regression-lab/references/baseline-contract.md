# Settled visual baseline contract

A valid baseline records URL, viewport, color scheme, reduced-motion state, screenshot checksum, console errors, failed responses, overflow, canvas presence, and capture timestamp. Bound font/network settling, record timeouts, warm through a bounded document region, return to the top, and record capture overrides before capture. A blank pre-animation frame is a failed baseline even when the page eventually renders.

Compare composition as well as pixels: first-view hierarchy, section rhythm, type rendering, crop intent, state completeness, mobile identity, focus, and static/reduced-motion identity. Never label an isolated component story as a finished site exemplar.

Capture helpers report `CAPTURED_REQUIRES_VISUAL_INSPECTION` or `CAPTURED_WITH_ISSUES`, never visual PASS. Manifests record page exceptions, browser/viewport emulation, bounded settling and capture overrides. Animations-disabled or fixed-element-suppressed images are transformed capture states, not natural-frame motion evidence. Paired artifacts are staged; overwrite is refused by default. A failed write rolls back newly published evidence; retained backups must be used if restoration itself fails.
