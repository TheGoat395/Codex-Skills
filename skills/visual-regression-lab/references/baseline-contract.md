# Settled visual baseline contract

A valid baseline records URL, viewport, color scheme, reduced-motion state, screenshot checksum, console errors, failed responses, overflow, canvas presence, and capture timestamp. Wait for fonts and network idle, allow entry motion to settle, scroll through the document to trigger lazy content, return to the top, then capture. A blank pre-animation frame is a failed baseline even when the page eventually renders.

Compare composition as well as pixels: first-view hierarchy, section rhythm, type rendering, crop intent, state completeness, mobile identity, focus, and static/reduced-motion identity. Never label an isolated component story as a finished site exemplar.
