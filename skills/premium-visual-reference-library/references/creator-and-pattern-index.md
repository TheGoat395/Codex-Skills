## Extraction template

For every selected reference, record:

- identity and original URL;
- observed desktop and mobile state;
- type system, composition, density, color/material, imagery, and interface chrome;
- motion trigger, duration, easing, choreography, and fallback;
- narrative and conversion job;
- technical inference, clearly labeled as inference unless source-backed;
- one principle to adapt, one detail to avoid copying, and one production risk;
- accessibility and performance concerns that must be corrected rather than inherited.
