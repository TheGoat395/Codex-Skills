# Brand Voice To UI Copy Guide

## Purpose

- Make interface words feel on-brand without becoming unclear or cute.

## Discovery Questions

- What are the brand voice traits and what do they forbid?
- Which UI moments need warmth, precision, authority, calm, play, or restraint?
- Where must clarity override personality?
- What repeated terms need a glossary?

## Implementation Rules

- Create voice rules for UI states, not only marketing paragraphs.
- Keep functional labels clear before adding personality.
- Use consistent terms for the same actions and objects.
- Avoid jokes in errors, payments, booking, security, medical, legal, or high-stress states.
- Document examples and non-examples.

## Useful Patterns

- Voice map: trait, do, don't, UI examples.
- Button labels: direct action with brand-appropriate restraint.
- Empty state: what happened, why it matters, next action.
- Error: problem, fix, reassurance if needed.

## Anti-Patterns

- Brand voice means every button is quirky.
- Same action has five names.
- Cute error copy during serious failure.
- Marketing headline tone pasted into form labels.

## QA Checklist

- Audit repeated terms, CTAs, errors, and empty states.
- Check clarity under mobile constraints.
- Review high-stakes moments for restraint.
- Create a few reusable copy patterns.

## Acceptance Criteria

- UI copy sounds like the brand and remains usable.
- Terminology is consistent.
- Microcopy improves confidence and flow.
