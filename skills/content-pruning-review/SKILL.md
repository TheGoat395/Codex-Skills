# Content Pruning Review

Use this skill to make the page sharper by deleting what dilutes the main decision path.

## Workflow

1. Inspect the requested copy/content, intended action, source facts and brand conventions; expand to IA, forms or metadata only if affected.
2. Read [Content Pruning Review Guide](references/content-pruning-review-guide.md) before changing headings, sections, CTAs, metadata, labels, or UI copy.
3. Draft from evidence: real product/service facts, proof, objections, user tasks, and constraints.
4. Replace generic claims with specific language or remove them.
5. When implementing copy, inspect its affected rendered desktop/mobile states for wrapping and clarity. Copy-only output does not require site changes.

## Scoped execution

Apply the [shared web contract](../website-operating-rules/references/scoped-web-contract.md) once when execution crosses phases; reuse it if already read. Load only the specialist guidance relevant to the requested surface and deliverable.
