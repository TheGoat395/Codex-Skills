# Gemini CLI Adapter

Gemini CLI supports project context files such as `GEMINI.md`. This adapter provides a compact project context file based on the public core's website and agent-quality standards.

## Install

From a target project:

```bash
cp path/to/Codex-Skills/adapters/gemini-cli/GEMINI.md ./GEMINI.md
```

If the project already has a `GEMINI.md`, merge the adapter content into the existing file instead of overwriting it.

## Optional Settings

Gemini CLI can be configured to use context filenames such as `GEMINI.md` or `AGENTS.md`. If your project uses `AGENTS.md`, copy the adapter content there instead.

## Best Use

Use this adapter for:

- website planning
- premium frontend direction
- non-generic UI review
- responsive and accessibility checks
- motion discipline
- evidence-led reasoning and completion verification
- final handoff summaries

## What This Adapter Is

- A compact Gemini project context file.
- A summary of the repo's strongest public-core standards.
- A practical bridge for teams that use Gemini CLI instead of Codex.

## What This Adapter Is Not

- Not a full install of all 80 `SKILL.md` folders.
- Not a replacement for the generated inventory or curated collections.
- Not an endorsement by Google.

For full skill behavior, inspect the `skills/` directory and copy relevant instructions manually into the project context.
