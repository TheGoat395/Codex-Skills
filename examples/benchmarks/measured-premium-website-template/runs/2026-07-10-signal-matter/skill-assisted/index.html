SM / Process / 03

Built in
three passes.

Every project starts with attention. We find the signal, chart its edges, and give it somewhere to live.

01Listening now
  1. 01

    Listen

    We stay with the room long enough to hear what is already moving through it: the hum, the gap, the held breath.

  2. 02

    Map

    We translate those observations into coordinates, pathways, and a score that lets the architecture participate.

  3. 03

    Materialize

    We install the invisible: calibrated sound, responsive light, and a field that changes when you enter it.
