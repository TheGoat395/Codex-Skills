# Atlas Benchmark Prompt

Create a static website for a fictional open-source maintenance tool named Atlas.

The page must include:

- a hero section
- a three-item feature section
- an install command block
- a maintainer workflow section
- a final call to action
- responsive desktop and mobile behavior
- semantic HTML, visible focus states, accessible labels, and reduced-motion support
- a distinctive, professional technical/open-source visual direction rather than generic SaaS styling
- a working copy-install-command interaction and mobile navigation toggle

Use only `index.html`, `styles.css`, and `script.js`. Use no external dependencies or network assets. Run local syntax and structure checks and summarize the result.

The exact prompt above was used for both runs. The baseline had no Codex-Skills source available. The skill-assisted run had the public repository's website direction, implementation, accessibility, performance, and handoff skills available as local source.
