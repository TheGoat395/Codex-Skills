02 / Start local

One command.
Zero ceremony.

Atlas runs beside your repository, not between it and your team. Install the CLI, point it at a codebase, and keep the first pass read-only.

terminalmacOS · Linux · WSL
$ npm install --global @atlas/cli

Then run atlas map in the root of your repository.
